# 归云录：江岸危局

一个完全原创、无需服务端的浏览器 3D 武侠 MMORPG 竖切原型。玩家会与四名 AI 队友完成山门接援、山路迎敌、轻功过断桥、寺院守卫、五人首领战和返回交付的完整任务。

## 启动

直接双击或用浏览器打开项目根目录的 `index.html`。游戏不会请求服务端，也不会在运行时调用 AI API。

## 操作

- 移动：`WASD` 或方向键
- 镜头：拖动鼠标；手机横屏拖动右侧空白区域
- 跳跃 / 二段跳：`Space`
- 轻功疾冲：`Shift`
- 普通攻击 / 闪避：`J` / `K`，也可使用鼠标左键 / 右键
- 回风式 / 穿云刺：`Q` / `E`
- 队伍集火 / 归队：`R`
- 交互：`F` 或 `Enter`
- 全屏 / 暂停：`G` / `Esc`

手机横屏提供摇杆、镜头拖动区和完整动作按钮；手机竖屏会提示旋转设备。

## 玩法要点

- 断桥中段没有隐形地面，必须利用二段跳、疾冲、踏水宽限和六个窄落脚点；落水会回到最近安全点。
- 枪卫、弓手、医者和影行会真实参战，也会被敌人与首领攻击。医者群疗会恢复实际气血。
- 首领具有近身范围技“断岳回风”、地面预警“焚脉落印”和可破招引导“锁脉夺息”。后者需要切换集火并配合“穿云刺”。
- 战斗倒地会重置当前防守波或首领战，但不会让任务倒退。

## 技术结构

- `src/world.js`：静态世界、地面查询、断桥与关卡区域
- `src/entities.js`：低多边形角色、武器挂点与即时技能效果
- `src/combat.js`：队友 AI、防守波次、治疗和首领机制
- `src/ui.js` / `ui.css`：桌面 HUD、手机摇杆与动作按钮
- `src/core.js`：任务状态机、输入、移动物理、镜头和测试状态接口
- `vendor/three.min.js`：内置 Three.js r149，MIT 许可证见 `vendor/THREE-LICENSE.txt`

角色会贴合不同高度的地面，并使用确定性分离避免战斗中互相叠入；山门、村屋、寺院、树干与 NPC 都有简化行走碰撞，移动和闪避不能穿墙。

图像生成素材位于 `assets/generated/`。完整生成提示词和用途见同目录说明。
